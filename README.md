# Romany Adel — AI & Machine Learning Portfolio

A responsive, single-page portfolio presenting my work across **AI, machine learning, NLP, and data engineering**.

## What you'll find

- About, skills, services, education, and contact sections
- Featured case studies for **MediSimplify**, **AnomX**, and a cardiovascular disease prediction project
- Interactive project case-study modals
- Responsive navigation, motion effects, and reduced-motion support
- A contact form interface and links to GitHub, LinkedIn, and email

## Built with

- HTML, CSS, and JavaScript
- Google Fonts: Space Grotesk, Inter, and JetBrains Mono

## Run locally

~~~bash
git clone https://github.com/adelromany308-droid/Romany-Adel-portfolio.git
cd Romany-Adel-portfolio
~~~

Open **index.html** in a browser. The profile image is stored in **romany-photo.png**.
