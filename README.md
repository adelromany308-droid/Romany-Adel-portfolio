# Romany Adel — AI, React & Backend Portfolio

A responsive personal portfolio showcasing my work across **AI and machine learning, NLP, data engineering, and full-stack web development**.

## Live portfolio

[Open the portfolio](https://adelromany308-droid.github.io/Romany-Adel-portfolio/)

The site is published with GitHub Pages and deploys automatically from the **main** branch.

## What you'll find

- About, skills, services, experience, education, and contact sections
- Interactive case studies for **MediSimplify**, **AnomX**, and a cardiovascular prediction project
- A featured **UniQueue** case study covering its React frontend and Node.js backend
- A filterable skills section for AI/ML, NLP, data, and React/backend technologies
- Responsive layouts, reduced-motion support, and accessible focus states

## Technology

- **Frontend:** HTML, CSS, JavaScript
- **AI and data:** Python, machine learning, NLP, data engineering
- **Full-stack project:** React, Vite, Node.js, Express, MongoDB, Socket.IO, JWT

## Run locally

~~~bash
git clone https://github.com/adelromany308-droid/Romany-Adel-portfolio.git
cd Romany-Adel-portfolio
~~~

Open **index.html** in a browser. Keep **romany-photo.png** beside the page.
